# راهنمای نصب و استفاده‌ی محلی راوان

## نکته‌ی مهم درباره‌ی کیفیت

این نسخه یک **نمونه‌ی پژوهشی بسیار کوچک** است، نه یک دستیار آماده. پاسخ‌های آزمایش‌شده عمدتاً خالی یا نامفهوم بودند. کیفیت مکالمه‌ی فارسی هنوز طبیعی نیست؛ برای درس، سلامت یا تصمیم مهم به جوابش تکیه نکنید. فایل‌های وزن واقعاً از مقداردهی تصادفی آموزش داده شده‌اند، اما داده و محاسبه‌ی فعلی برای رسیدن به هدف شما کافی نبود.

## چیزهایی که لازم است

- Windows 11 نسخه‌ی ۶۴بیتی.
- فایل‌های مخزن، شامل `model\ravan-v2-Q4_0.gguf` و پوشه‌ی `app`.
- یک‌بار دریافت runtime رسمی `llama.cpp` برای Windows x64 CPU از [صفحه‌ی release رسمی](https://github.com/ggml-org/llama.cpp/releases/tag/b11768): فایل `llama-b11768-bin-win-cpu-x64.zip` (حدود ۲۴ مگابایت در release بررسی‌شده). اتصال اینترنت فقط برای این بار لازم است.
- Python، PyTorch، Node.js، API key یا حساب پولی روی رایانه لازم نیست.

**پردازنده‌ی Pentium G3250 AVX2 ندارد.** مشخصات Intel SSE4.1 و SSE4.2 را اعلام می‌کند. بنابراین از بسته‌ای که صریحاً AVX2 می‌خواهد استفاده نکنید. بسته‌ی CPU عمومی رسمی باید نسخه‌ی قابل‌حمل CPU باشد؛ اما خود فایل release در این محیط قابل دریافت نبود و روی G3250 آزمایش نشده است. اگر خطای `Illegal instruction` دیدید، runtime را اجرا نکنید؛ به بخش «ناسازگاری پردازنده» بروید.

## نصب

1. پوشه‌ی پروژه را در محلی مثل `C:\Ravan-AI` قرار دهید.
2. فایل ZIP رسمی CPU را با File Explorer باز کنید و `llama-server.exe` به‌علاوه‌ی همه‌ی DLLهای کنار آن را در پوشه‌ی `windows` کپی کنید؛ در کنار `run-chat-v2.bat` قرار بگیرند.
3. در File Explorer روی `windows\run-chat-v2.bat` دوبار کلیک کنید.
4. مرورگر باید صفحه‌ی محلی را باز کند. اگر نشد، پس از آماده‌شدن سرور به `http://127.0.0.1:8080` بروید.
5. پنجره‌ی سیاه را تا پایان گفت‌وگو نبندید. برای خاموش‌کردن موتور همان پنجره را ببندید.

این برنامه مدل را از اینترنت نمی‌گیرد. صفحه‌ی وب فقط به موتور محلی روی همان رایانه وصل می‌شود؛ پیام‌ها به سرویس خارجی فرستاده نمی‌شوند. سرور روی loopback بسته شده؛ آن را روی شبکه یا اینترنت عمومی باز نکنید.

## تاریخچه و حافظه

تاریخچه و یادداشت‌های حافظه در `localStorage` مرورگر ذخیره می‌شوند. هیچ یادداشتی بدون واردکردن و زدن «ذخیره‌ی یادداشت» ثبت نمی‌شود. می‌توانی هر یادداشت را ببینی، ویرایش، حذف یا به JSON صادر کنی؛ تاریخچه هم خروجی و دکمه‌ی پاک‌کردن دارد. این موارد فقط اطلاعات ذخیره‌شده در مرورگرند و **وزن‌های مدل را تغییر نمی‌دهند**. داده‌های localStorage رمزگذاری‌شده نیستند؛ اطلاعات محرمانه وارد نکن.

## اگر موتور شروع نشد

- اگر `llama-server.exe was not found` دیدی، فایل اجرایی و DLLهای release را در `windows` قرار بده.
- اگر مدل پیدا نشد، ساختار پوشه را تغییر نده: فایل باید در `model\ravan-v2-Q4_0.gguf` باشد.
- اگر `Illegal instruction` آمد، پردازنده یا فایل runtime با هم سازگار نیستند. بسته‌ی AVX2 را پاک کن و یک نسخه‌ی llama.cpp با SSE4.2 و بدون AVX/AVX2/FMA/F16C/BMI2 بساز یا نسخه‌ی CPU پایه‌ی تأییدشده پیدا کن. چنین باینری ویندوزی در این مخزن ارائه نشده است.
- برای آزمایش صرفِ بارگذاری، از پوشه‌ی ریشه اجرا کن: `llama-server.exe -m model\ravan-v2-Q4_0.gguf --host 127.0.0.1 --port 8080 --ctx-size 512 --threads 2 --parallel 1 --path app`.

## پاک‌کردن اطلاعات

از دکمه‌های «پاک‌کردن گفت‌وگو» و «حذف» کنار یادداشت‌ها استفاده کن. برای پاک‌کردن کامل، داده‌های سایت `127.0.0.1` را از تنظیمات مرورگر حذف کن. فایل‌های export شده را جداگانه از پوشه‌ی Downloads پاک کن.
